# Device guide

Always use the live catalog for names and prices. These rules say which item suits which need.

## Laptops

| Need | Catalog item | Why |
|---|---|---|
| Developer working on Windows, Linux tools, containers | Development Laptop (PC) | Dell XPS 13 sized for development tools |
| Developer building for macOS or iOS, or who asks for a Mac | Developer Laptop (Mac) | MacBook Pro; needed for Apple platform development |
| Sales or anyone who travels most weeks | Sales Laptop | Light machine for travel and customer visits |
| Everyone else (office, finance, HR, operations) | Standard Laptop | Lenovo Carbon X1, the standard build |
| Temporary machine while theirs is repaired or reimaged | Loaner Laptop | Free short-term loan; no approval spend |

If a developer doesn't say which platform, recommend Development Laptop (PC) and offer the Mac as the alternative.

## Monitors

Recommend Standard 24" Monitor for most desks; Standard 27" Monitor for developers, designers or anyone who works with several windows side by side; Standard 22" Monitor for small desks. Add StarTech USB to DVI Adapter only if the employee mentions an older DVI screen.

## Phones and tablets

Apple iPhone 13 is the standard phone; Apple iPhone 13 pro only when the employee's role needs the better camera or storage. iPad mini for note-taking on the move; iPad pro only for design or field work.
